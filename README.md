# DocDoc

A Flutter mobile application for booking doctor appointments

---

## ✨ Overview


This repo contains a cross-platform Flutter project (Android, iOS) implementing the DocDoc app UI, networking, and Firebase configuration used during development.

Key technologies:

Flutter (Dart)

Firebase (project configuration present)

GitHub Actions CI workflows

---

## features

- Home screen UI and API integration

- Doctor filtering features (filter by speciality id)

- Token storage and secure token handling (shared_preferences and flutter_secure_storage added)

- CI workflows and GitHub Actions

- Multiple flavors (development & production )
